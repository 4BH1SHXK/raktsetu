# RaktSetu

A Smart Blood Request Coordination Platform.

## Overview

RaktSetu connects people who need blood with potential blood donors through a location-based coordination system.

## Features

- User authentication
- Donor registration
- Blood request management
- Location-based donor matching
- Donor contact requests
- Request status tracking

## Tech Stack

- Python
- FastAPI
- React
- PostgreSQL
- SQLAlchemy
- Alembic

Currently under development.
